# aria_router

Flutter SDK for [ariarouter](https://github.com/ariacompute/router). Published on pub.dev as **`aria_router`** (`flutter pub add aria_router`); import `package:aria_router/ariarouter.dart`. Instance `setup` is in-memory (`baseUrl` / `token`) and does not write `ariarouter.yml`. Native FFI uses `libariarouter_ffi`.
